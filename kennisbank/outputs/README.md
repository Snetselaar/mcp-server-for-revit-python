# outputs — gegenereerde antwoorden

Alles wat `/kb-vraag` en `/kb-check` opleveren. Door Claude geschreven,
niet handmatig bewerken.

**Naamgeving:** `JJJJ-MM-DD-onderwerp.md`, bij health checks
`JJJJ-MM-DD-healthcheck.md`.

**Niets wordt overschreven.** Een nieuwe vraag over hetzelfde onderwerp levert
een nieuw bestand op. Dat de antwoorden na verloop van tijd van elkaar
verschillen is informatie, geen probleem — `/kb-check` gebruikt het om te zien
waar het begrip is verschoven.

Een output is geen wiki-artikel. Blijkt een antwoord blijvend waardevol, dan
gaat het via `raw/` of rechtstreeks via `/kb-verwerk` de wiki in. Een output op
zichzelf wordt nooit door de wiki als bron aangehaald zonder dat de
onderliggende bron erbij staat.
